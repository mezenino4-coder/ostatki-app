# Остатки склада

Утилита учёта остатков на двух складах:

- **Центральный склад** — старая база (только уменьшается, пополняется не из программы);
- **Центральный синий склад** — новая база (пополняется перемещениями).

## Возможности

1. **Пополнение** — распознавание скрина «Перемещение запасов» (1С УНФ) через OCR и приход на синий склад.
2. **Проверка наличия** — вставить спецификацию (код + количество) → список по обоим складам + автосписание с новой базы + печать «Задание на сборку».
3. **Проверка базы** — сверка новой базы с выгрузкой 1С УНФ (наименование | НФ-код | ячейка).
4. **База** — просмотр, поиск, добавление/изменение/удаление, слияние и перенос ячеек.

## Запуск

### Windows

1. Установить Python 3.10+ с [python.org](https://python.org) (обязательно отметить **«Add python.exe to PATH»**).
2. Запустить `start.bat` — он сам создаст виртуальное окружение и установит зависимости (первый раз — несколько минут).
3. В папке должен лежать файл `ostatki_po_skladu.tsv` (старая база, колонки: **Наименование | Код | Ячейка**).

### Linux

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Примечания

- База SQLite (`ostatki.db`) создаётся автоматически при первом запуске.
- Модели OCR лежат в папке `models/`.
- Печать «Задание на сборку» на Windows использует `pywin32` (ставится автоматически из requirements.txt).
